# Seguridad

El toolkit es local y no contiene credenciales ni conexiones automáticas. No pegues tokens, datos personales o material confidencial en las habilidades. Si una habilidad requiere una fuente externa, usa una integración autorizada y registra las fuentes; nunca conviertas una guía en una acción de publicación, envío, compra o borrado sin una confirmación separada.
